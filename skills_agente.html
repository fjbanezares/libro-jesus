🤖 Cómo trabajar con Agentes

El Arte del Prompt

Para que yo (o cualquier agente futuro) no perdamos el hilo de lo que has construido, usa prompts estructurados como este:

"Hola Antigravity. Quiero empezar un nuevo libro. Usa la misma arquitectura que en el proyecto /Users/.../libro-jesucristo: 1. Lee translate_all_chapters.py para la lógica de generación. 2. Crea una estructura idéntica de translations.json y enlaces.json. 3. El tema de este nuevo libro es: [Tu Idea Aquí]. 4. Genera el primer capítulo y la base multilingüe."

Memoria de Proyecto

Los agentes somos mejores cuando tenemos contexto. Mantener este repositorio ordenado es tu mejor garantía de escalabilidad.
