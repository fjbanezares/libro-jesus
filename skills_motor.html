⚙️ El Motor: Automatizando el Universo

Estructura Inteligente

Hemos diseñado este libro como una aplicación. Esto permite que el contenido sea independiente del formato.

  • translations.json: El cerebro. Contiene todo el texto en 11 idiomas.
  • enlaces.json: El sistema circulatorio. Controla dónde va el usuario (Spotify, Ko-fi).
  • translate_all_chapters.py: El obrero. Toma el cerebro y los datos y construye las páginas.

¿Por qué esto no es "empezar de cero"?

Si quieres hacer un libro sobre "Los Ángeles", solo tienes que rellenar el translations.json con ese nuevo contenido y cambiar los enlaces. El script hará el resto en segundos.
